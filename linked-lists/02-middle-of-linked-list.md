# 876. Middle of the Linked List

## Problem Description
Return the middle node of a singly linked list. If there are two middle nodes, return the second middle node.

## Approach
Use the two-pointer technique (fast and slow pointers). Advance `fast` by two steps and `slow` by one step per iteration.

## Complexity
- **Time Complexity:** O(N)
- **Space Complexity:** O(1)
